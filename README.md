🕵️ OSDC Mystery Room — Case #001

The Missing Commit

A fictional detective-style investigation website created for the Open Source Developers Club (OSDC).

📌 About

At 02:13 AM, an unknown commit appeared in the OSDC repository.

Three files were deleted, the repository was locked, and four developers had different levels of access.

Your task is to examine the case file, suspects, repository activity, evidence, terminal logs, and clues and draw your own conclusion.

✨ Features

* 🕵️ Case investigation storyline
* 👨‍💻 Fictional developer suspects
* 📁 GitHub-inspired repository interface
* 🔍 Evidence room
* 💻 Fake terminal and Git logs
* 🧩 Detective-style clue board
* 📝 Final investigation form
* 📱 Responsive design
* ♿ Semantic and accessible HTML

🛠️ Technologies

This project intentionally uses only:

* HTML5
* CSS3

No JavaScript, frameworks, libraries, backend, or APIs are used.

osdc_mystery_room/

🚀 Running the Project

No installation or setup is required.

Simply download or clone the repository and open:

index.html

in any modern web browser.

🎯 Purpose

This project was created as a beginner-friendly demonstration of:

* Semantic HTML
* HTML forms
* Tables
* Lists
* Navigation
* CSS layouts
* Flexbox
* CSS Grid
* Responsive design
* CSS animations and hover effects
* Developer-oriented UI design

It is also designed to provide a foundation for adding JavaScript interactions in the future.

⚠️ Disclaimer
